Monthly Todo Planner is a sophisticated productivity application designed to help users structure their month, break down complex goals into weekly tasks, and visually track daily habits. Built with React Native and Expo, the app features a highly optimized, native-feeling architecture with custom premium UI elements.

---

## Key Features

- **Visual Habit Tracking**: Monitor your routine with a beautifully animated 30-day history grid. Automatically tracks streaks and daily percentage completion.
- **Weekly Task Management**: Break down your monthly goals into four distinct, highly customizable weekly segments. Attach external resources (links, articles) directly to tasks.
- **Dynamic Progress Bar**: A real-time, animated progress bar visualizing your completion status across the entire month.
- **Smart Local Reminders**: Set custom daily alarm notifications to keep yourself accountable. Features snooze capabilities directly from the notification tray.
- **Premium Liquid Interface**: A sleek, dark-mode-first aesthetic with smooth micro-animations, dynamic haptic feedback, and frosted glass-like overlays. fully tailored for modern mobile UX.
- **100% Offline & Private**: All of your habits, tasks, history, and reminders are securely stored locally on your device via AsyncStorage. No cloud tracking.

## Technology Stack

- **Framework**: React Native & Expo (EAS Build)
- **Navigation**: React Navigation 7
- **Animations**: React Native Reanimated
- **Storage**: AsyncStorage (Offline-first data persistence)
- **Notifications**: Expo Notifications (Local scheduling)
- **Performance Optimized**: Configured with ABI splitting (arm64-v8a exclusive), Proguard shrinking, and Hermes JS engine for maximum speed and minimal APK size.

## Getting Started for Developers

If you want to clone and run this project locally, follow these steps:

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Expo Go App**: Installed on your iOS or Android device.

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Atifhasan250/monthly-todo-planner.git
   cd monthly-todo-planner
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start the Metro Bundler**
   ```bash
   npm start
   ```

### Running the App
- **Physical Device**: Scan the QR code displayed in the terminal using your phone's camera (iOS) or the Expo Go app (Android).
- **Simulators**: Press `a` to open on an Android Emulator, or `i` to open on an iOS Simulator.
